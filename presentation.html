The Flawed Status Quo

The 3 Fatal Flaws of Traditional Watchlists

Why TradingView, Yahoo Finance, and Apple Stocks fail retail and institutional investors.

1. Red/Green Noise Trap

Flat tables sort tickers alphabetically and color them red or green based on arbitrary 24-hour moves.

A +2% move on high-beta Swiggy is everyday noise. A +2% move on low-beta HUL while FMCG is down -1.5% is a massive institutional signal. Flat lists treat them identically.

2. Missing Temporal Baseline

Standard tools only calculate percentage changes from the 9:15 AM market open.

If you step away for 2 hours between 1:00 PM and 3:00 PM, you have no way of knowing what moved while you were away vs. what was already priced in this morning.

3. Isolated Silos

Stocks exist in complex supply chains, joint ventures, and conglomerate ecosystems.

When Tata Motors wins an EV contract, traditional tools don't show that Tata Power (chargers) and Sona BLW (drivelines) are about to surge, while Maruti faces margin drag.

Engineering Depth

Zero-Hallucination Session Persistence

W3C Beacon API guarantees reliable exit tracking even during abrupt tab termination.

🛑 The Broken Fetch Pattern

When users close a laptop lid, terminate a browser tab, or switch apps, standard window.fetch() and axios requests are instantly killed by the browser runtime.

Result: The server never learns the user left, and exit prices are lost forever.

⚡ The W3C Beacon Solution

Nexus utilizes navigator.sendBeacon('/api/session/leave').

The browser hands the JSON payload directly to the operating system's background network process. It completes reliably even after the tab process dies.

⏱️ Return Experience & Time-Machine Scrubber

Upon return, /api/session/return computes exact mathematical price deltas against the database checkpoint. Users can also use our interactive slider to scrub baselines across 15m, 1h, 4h, Market Open, or Yesterday Close.

Architecture

Production Scalability Architecture

Designed for high-throughput separation between hot-path reads and ingestion.

1. Pre-computed Ego Graphs

Rather than traversing the 150+ node network on every HTTP request, NetworkX pre-computes 1-hop and 2-hop ego-networks into an in-memory cache for sub-5ms lookups.

2. Indexed SQLite WAL Store

Compound B-Tree index idx_snapshots_ticker_time(ticker, timestamp) guarantees logarithmic time complexity $O(\log N)$ for delta calculations across historical ticks.

3. Production Horizon

Clean architectural boundaries allow immediate drop-in replacement with PostgreSQL + TimescaleDB for partition-tiered storage and Redis Pub/Sub for WebSockets.
